# Datheon_Data_Analytics_-_Power_BI_Internship


Project Overview

This repository contains two data analytics projects focusing on sales performance and customer retention. The projects use Python and Power BI to explore datasets, identify patterns, visualize results, and generate business insights.

Project 1: Superstore Sales Analysis

Objective

To analyze retail sales performance, customer purchasing behavior, profitability, and seasonal sales trends to support business decision-making.

Tools Used

Power BI

Power Query

DAX

CSV Dataset

Analysis Performed

Total sales, profit, and order analysis

Monthly sales trends and seasonality

Sales performance by region and product category

Customer purchasing patterns

Profitability analysis

Interactive dashboard development

Deliverables

Superstore Sales dataset

Power BI dashboard (.pbix)

Project 2: IBM Telco Customer Churn Analysis

Objective

To investigate customer churn and retention patterns in the telecommunications industry, identify high-risk customer segments, and estimate churn probabilities.

Tools Used

Python

Jupyter Notebook

Pandas and NumPy

Matplotlib and Seaborn

Scikit-learn

Analysis Performed

Data cleaning and exploration

Customer churn and retention rate calculations

Churn analysis by tenure and contract type

Payment method and monthly charges analysis

Identification of high-risk customer segments

Churn heatmap visualization

Logistic Regression for churn prediction

Deliverables

IBM Telco Customer Churn dataset

Jupyter Notebook (.ipynb)

Churn analysis visualizations

Project Structure

The repository contains datasets, source code, and dashboard files for both projects. The files are organized according to their respective analyses.

Conclusion

These projects demonstrate the application of data cleaning, exploratory data analysis, data visualization, business intelligence, and machine learning to real-world business problems. The analyses aim to provide insights that can support sales strategies, profitability improvements, and customer retention decisions.
